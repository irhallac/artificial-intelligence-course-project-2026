Course project / Method

How the test cases are created

The small program supplies the answer key. It is an ordinary fixed-rule program, not another AI model.

The basic idea

First create a small spatial arrangement or temporal structure whose answer is known. Then present that same case to a model in Turkish, English, or as an image.

A spatial example

Begin with an arrangement:

B is one square west of G.
J is one square south of B.

Select two entities and ask:

Where is G relative to J?

The correct answer is northeast.

The same case can now be written in matched forms.

Turkish

B, G'nin bir kare batısındadır. J, B'nin bir kare güneyindedir. G, J'nin hangi yönündedir?

English

B is one square west of G. J is one square south of B. In which direction is G from J?
Valid spatial cases. Each stated relation is a one-cell movement. After the movements are combined, the queried entities must be on the same row, the same column, or an exact diagonal. Overlaps and unequal horizontal–vertical offsets are not used.

What the program does

  1. Store a case as simple relations rather than natural-language sentences.
  2. Apply the spatial or temporal rules.
  3. Check that the case has a valid answer.
  4. Record the question, correct answer, and a stable case identifier.
  5. Create the Turkish, English, and any additional experimental versions from that same case.

The model receives the natural-language text or image. The answer program receives the structured case. The answer program does not need to understand Turkish, call an LLM, or judge an explanation.

Temporal cases

The same principle applies to temporal questions. Begin with events and their known before-and-after relations. The program orders the events or checks the requested temporal relation.

If the facts allow several answers, the case is excluded unless “cannot be determined” is deliberately included as an answer. The program must not silently choose one possible order.

From pilot to full experiment

  1. Use 5–10 cases to test the answer program, prompts, model access, and automatic scoring.
  2. Correct implementation problems found during the pilot.
  3. Fix the cases, conditions, prompts, and model settings.
  4. Run every planned condition on the full set. The default minimum is 50 base cases.
  5. Keep every raw response, including incorrect and invalid responses.

Do not remove difficult cases after seeing the model results.

Reference

StepGame uses this general approach to generate multi-step spatial questions. Its published example shows how an arrangement is converted into a story, question, and answer.
